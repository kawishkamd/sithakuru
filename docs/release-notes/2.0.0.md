**Sithakuru 2.0.0** — a lightweight Sinhala keyboard with a built-in emoji picker.

- New Singlish engine built on Helakuru's phonetic keymap: `ch`/`Ch`, `ksh`, `sRu`, `NG`, repaya, yansaya and rakaransaya now come out right
- Native emoji picker with category tabs, no bloat
- Wijesekara, Singlish and English layouts, adjustable font size, swipe to erase and move the cursor
