**Sithakuru 2.0.0** — a free, offline, lightweight Sinhala keyboard with built-in emoji, clipboard history, and English word suggestions.

- **Helakuru-compatible Singlish engine:** `ch`/`Ch`, `ksh`, `sRu`, `NG`, repaya, yansaya, and rakaransaya, plus an updated in-app Singlish help guide
- **Native emoji picker:** categories, recently used emojis, automatic filtering of unsupported glyphs on older Android versions, and clean single-tap backspace for multi-codepoint emojis
- **Clipboard history:** pin clips, auto-expire unpinned clips (1 hour / 1 day / never), clear all, and automatic skipping of sensitive, password, and incognito fields
- **English word suggestions** and autocompletion
- **Typing ergonomics:** optional haptic feedback, keypress popup preview, English auto-capitalization, and double-space for period
- **Customization & polish:** Wijesekara, Singlish, and English layouts, dark/light/custom colors, adjustable height and font size, swipe to erase or move the cursor, live test box in settings, and full English + Sinhala UI
